# 生成参数与采样

LLM 通常按当前位置的候选 Token 概率逐步生成文本。生成参数改变候选分布、候选集合或停止条件，但不会更新模型知识，也不会验证事实。

## 1. 从候选分数到下一个 Token

模型先为候选 Token 产生分数，再转换成概率分布。解码策略根据这个分布选择下一个 Token，然后把新 Token 加入序列并重复过程。

一次生成包含很多次选择。即使开头相同，中间一次不同选择也可能让后续分布逐渐分叉。因此，不要把“设置相同参数”误认为“所有请求都保证逐字相同”。服务端更新、硬件并行和未固定的随机源也可能带来差异。

## 2. temperature 控制分布形状

temperature 较低时，概率更集中在高分候选；较高时，分布更平缓，低分候选更容易被选中。它适合在稳定表达与多样探索之间调节。

它不是事实正确度旋钮：

- 低 temperature 可以稳定地产生同一个错误。
- 高 temperature 不会让模型获得训练后发生的新事实。
- 准确性仍依赖任务说明、可靠上下文、模型能力和验证流程。

## 3. top-p 限制候选集合

top-p 又称核采样。候选按概率从高到低排列，保留累计概率达到阈值的最小集合，再从其中采样。阈值较低通常减少长尾候选。

temperature 与 top-p 都会改变采样，初学阶段通常固定一个，只调整另一个并做评测。不能假设不同服务商对边界值、默认值和能否同时设置有完全相同的行为，应以所选 API 文档为准。

## 4. 输出上限与停止条件

最大输出 Token 用来限制延迟、成本和失控长输出。上限太小会导致答案或 JSON 被截断；上限过大则只是允许模型生成更久，不代表模型一定会用完。

停止序列可以在出现指定文本时结束生成，但它是文本层机制：停止文本可能出现在用户内容、代码或 JSON 字符串中。结构化输出优先使用专门的 Schema 能力和结束原因，不依赖脆弱的字符串截断。

还可能遇到重复惩罚、随机种子、候选数量等参数。只有在明确问题、建立评测集后再引入；参数越多，实验组合越多，越难判断改动因果。

## 5. 按任务选择起点

| 任务               | 首要目标   | 参数思路                                   |
| ------------------ | ---------- | ------------------------------------------ |
| 信息抽取、分类     | 稳定、合规 | 较低随机性，足够输出预算，Schema 验证      |
| 基于证据回答       | 忠于材料   | 较低随机性，明确引用与“不知道”，事实核验   |
| 标题或方案头脑风暴 | 多样性     | 适度提高随机性，一次生成多个候选后排序     |
| 代码修改           | 正确性     | 低到中等随机性，测试和静态检查比参数更重要 |
| 长篇创作           | 连贯与风格 | 给足预算，用大纲或分段生成控制结构         |

这些是实验起点，不是通用最优值。最终选择必须由项目自己的样本和指标验证。

## 6. 交互实验

打开[上下文与采样实验](../../projects/llm-usage-lab/index.html)，选择“采样分布”。调整 temperature 与 top-p，观察候选概率、被 top-p 保留的集合和一次示意选择。

页面使用固定教学分数计算，不代表真实模型输出。通过实验应能区分“概率重新分配”和“候选集合截断”。

## 7. 练习与验收

### 任务 1：单变量对照（必须）

准备 10 个固定输入，选择 temperature 或 top-p 其中一个参数设置三个值，另一个保持固定。每个配置至少运行两次，保存模型、参数、输出和评判结果。

通过条件：每组只改变一个主要变量；输入完全相同；结论同时说明质量和多样性，不能只展示一个最喜欢的样本。

### 任务 2：识别截断（必须）

用 fake 客户端返回“正常完成”和“达到输出上限”两种结束原因。应用必须在后者显示明确的不完整状态，并且不把被截断的结构化输出交给后续业务。

通过条件：两个分支都有测试；失败判断依赖结束原因或解析状态，不依赖回答最后是否有句号。

### 任务 3：为任务写参数决策记录（必须）

为“资料摘要”和“标题头脑风暴”各选择一组参数起点，说明目标、风险、评测方法和何时重新调整。

通过条件：两个任务没有仅凭“temperature 越低越准确”得出结论；明确写出参数不能替代事实和 Schema 验证。

### 知识检查（必须）

解释 temperature 与 top-p 的区别、输出上限与上下文窗口的关系，以及相同参数为何仍不一定逐字复现。

完成后学习 [Prompt 设计](prompt-design.md)。
