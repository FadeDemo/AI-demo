# 流式输出与可靠性

流式输出让应用在完整回答结束前逐步收到事件，可以降低用户感知等待时间，但不会缩短模型完成全部生成的总时间。可靠的客户端需要把“开始收到内容”和“请求完整成功”分开记录。

## 1. 流不是任意字符串片段

SDK 可能产生多类事件：文本增量、工具参数增量、usage、结束原因、错误和心跳。应用应按事件类型处理，不能把所有字段直接拼接到终端。

结构化输出或工具参数可能分散在多个事件中。只有收到明确完成事件并通过解析与验证后，才能交给业务层。流中途断开时，已经显示的文本可以保留给用户参考，但必须标记为不完整。

## 2. 两种延迟

- **首 Token 延迟（TTFT）**：从发出请求到收到第一个可展示内容。
- **总耗时**：从发出请求到完成、失败或取消。

流式输出主要改善前者的体验。还可记录输出速率，但不同模型和服务对事件粒度定义不同，比较时要保持测量口径一致。

## 3. 超时与取消

至少区分连接超时、等待首事件超时、流空闲超时和整个请求的总期限。只设置一个很大的总超时，会让连接故障或卡住的流长时间占用资源。

用户取消时，应用要传播取消信号、停止读取流、释放连接，并禁止继续执行尚未开始的工具。取消是独立结果，不应记录成模型服务错误。

## 4. 哪些错误可以重试

| 失败                       | 默认策略                                     |
| -------------------------- | -------------------------------------------- |
| 连接失败、超时             | 在预算内有限重试，加入退避和随机抖动         |
| 429 限流                   | 尊重服务端等待提示，再有限重试               |
| 部分 5xx                   | 有上限地重试，记录服务状态                   |
| 认证或权限失败             | 不重试，修复凭据或权限                       |
| 无效请求、上下文过长       | 不原样重试，先修复输入                       |
| Schema 或业务规则失败      | 可选择一次受控修复，不归入网络重试           |
| 流已输出部分文本后连接中断 | 默认不自动向用户重复拼接，明确标记并决定重做 |

指数退避常写为逐次增加等待时间，并加入随机抖动，避免大量客户端同时重试。重试必须受最大次数和总期限共同限制。

## 5. 幂等性与副作用

纯文本生成重复执行通常只增加成本；包含写工具的流程可能造成重复发信、重复创建或重复扣费。逻辑操作应生成幂等键，在重试或客户端重放时复用，并由执行系统记录已完成结果。

不要在收到不完整流后无条件重放整个 Agent 循环。模型可能已经触发并完成工具，只是最终响应丢失。应先查询操作状态，或让工具自身按幂等键去重。

## 6. 限流与并发

客户端要同时限制进行中的请求数和单位时间请求量。无限并发会放大 429、超时、内存占用和费用。排队也需要上限；队列满时应快速拒绝或降级，而不是让请求无限等待。

服务端给出的请求数限制和 Token 限制是不同维度。大量短请求可能撞请求数限制，少量超长请求也可能撞 Token 限制。

## 7. 练习与验收

### 任务 1：组合流式事件（必须）

用 fake 流依次产生三个文本增量、usage 和完成事件。实现消费者并记录 TTFT 与总耗时。

通过条件：文本顺序正确；只有完成事件到达后状态才是成功；usage 没有作为正文显示；时间测试使用可控时钟而不是实际等待。

### 任务 2：处理中途失败与取消（必须）

分别模拟两个增量后异常，以及用户在第一个增量后取消。

通过条件：两者都不标记为完整成功；取消不会记录成 5xx；异常或取消后不执行工具；资源清理可由测试观察。

### 任务 3：实现重试分类（必须）

为超时、429、503、认证失败和无效请求建立分类。使用 fake 时钟验证退避，不在测试中真实等待。

通过条件：前三类在上限内重试；后两类立即失败；所有路径都不超过最大次数和总期限；日志包含 attempt 与最终类别。

### 任务 4：验证幂等（必须）

模拟一次创建草稿操作在响应丢失后被重放，使用同一幂等键执行两次。

通过条件：底层只产生一个草稿；第二次返回第一次的稳定结果；不同幂等键可以创建不同草稿。

### 知识检查（必须）

解释流式为何改善感知延迟但不必然减少总耗时、429 与认证失败为何采用不同策略、以及有副作用工具为何必须考虑幂等。
