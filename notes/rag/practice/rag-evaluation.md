# RAG 评测

系统回答错了，可能是没有找到证据，也可能是找到了却没有送给模型，或者模型读到了仍然写错。本课把这些情况分别留下记录，让一次修改带来的变化有据可查。

完成后，你会有 50～100 条固定问题，以及能比较两个配置的评测入口。报告既包含自动计算的检索指标，也包含人工核对的回答与引用评分。

## 学习前提与本课范围

沿用第二阶段的[检索评测](../foundations/retrieval-evaluation.md)入口、固定问题和无答案约定。第三课提供原文证据范围，第四课提供身份上下文的可见范围，第五课提供完整的查询流程。

本课权限用例直接使用第四课的可信测试身份，检查检索与回答中的隔离。第七课才接通外部身份认证。评测不要求提前部署容器，也不把后续故障恢复当作本课通过条件。

## 1. 给每题留下可复查的判断依据

一条评测记录应能重现输入条件，也能解释什么算答对。

| 内容     | 要记录什么                                     |
| -------- | ---------------------------------------------- |
| 问题身份 | 稳定编号、原问题和题目类别                     |
| 输入条件 | 资料快照、调用者组、多轮历史或单轮说明         |
| 预期行为 | 回答、依据不足、澄清或不支持                   |
| 必要事实 | 人工核对原文后列出的应答要点                   |
| 必要证据 | 文档版本与原文区间，固定切法时可另列片段编号   |
| 禁止事项 | 不得泄露的教学标记、不得编造的内容或执行的动作 |

人工标注应查看该身份可见的完整资料。工作人员有答案、游客没有可用依据的同一个问题，需要两条输入条件不同的记录。资料更新后保存新的标注版本，不覆盖已经用来比较的旧标注。

可以按下面的 50 题分配开始扩充，再根据实际语料调整数量。类别可以多选，统计总题数时每个编号只算一次。

| 主要类别           | 示例数量 | 要检查的差别                   |
| ------------------ | -------- | ------------------------------ |
| 单段事实           | 10       | 资料明确写出的条件和数字       |
| 同义或模糊表达     | 8        | 表述变化与必要澄清             |
| 精确标识符         | 6        | 编号和配置名是否匹配           |
| 跨段、跨文档或多轮 | 6        | 多项依据与历史是否齐全         |
| 无答案             | 6        | 是否承认资料不足               |
| 过期资料           | 4        | 是否使用指定当前版本           |
| 内容冲突           | 4        | 无法确定时是否停止下结论       |
| 权限受限           | 3        | 只在可见资料内回答             |
| 注入资料           | 3        | 攻击文字到达证据后是否影响规则 |

沿用的 20 题属于这 50～100 题之内。拆分一部分作为调整配置的开发集，另一部分作为冻结的比较集，分别报告。不要看过比较结果后反复改同一批问题，再把它称作独立验证。

## 2. 找到证据和送入证据分开检查

沿用 Recall@K、Precision@K 和 MRR@K，明确候选单位和分母。比较不同检索方法时固定片段集合，人工标注对应的相关片段。同一相关文档中的任意片段不能自动算作命中。

比较不同切块策略时，用第三课的原文证据单元覆盖率，避免切块变化导致相关片段数变化而无法直接比较。检索候选与最终送入模型的证据各算一份覆盖率。

假设一个问题需要 D1 的重试条件和 D3 的日志规则。检索已经找到两者，预算选择却只保留 D1，那么检索覆盖率是 1，送入证据覆盖率是 1/2。这时先检查预算与证据选择，比继续优化初检更能解释当前缺口。

## 3. NDCG 怎样区分相关程度

前面的二元相关标注只区分相关与不相关。分级相关允许记录“直接回答”和“有帮助但不完整”的区别。归一化折损累计增益，简称 NDCG，会把较高相关等级出现在靠前位置的排名评得更高。

本课采用三级标注，0 表示无关，1 表示包含部分必要信息，2 表示直接支持该题的一项完整必要事实。分级由人对照原文完成。本课固定使用指数增益和以 2 为底的对数折损。

```text
DCG@K = 从 i=1 到 K 求和 (2^rel_i - 1) / log2(i + 1)
NDCG@K = DCG@K / IDCG@K
```

rel_i 是第 i 位的相关等级。IDCG 是把当前快照中全部可见片段按人工等级从高到低排列后，同样取前 K 位算出的理想 DCG，不能只在检索已经返回的候选中找理想顺序。少于 K 个返回结果时，空位等级为零；理想值为零时，本课记为不适用，单独报告。

假设共有三个片段，A、B、C 的等级分别为 0、2、1。实际顺序为 A、B、C，理想顺序为 B、C、A。

| 计算        | 结果                                   |
| ----------- | -------------------------------------- |
| 实际 DCG@3  | `0 + 3/log2(3) + 1/log2(4)`，约 2.3928 |
| 理想 IDCG@3 | `3 + 1/log2(3) + 0`，约 3.6309         |
| NDCG@3      | 约 0.6590                              |

先把 B 移到首位，再重算。即使三篇都还在前三位，NDCG 仍会变化。[ir-measures 的指标文档](https://ir-measur.es/en/latest/measures.html#ndcg)列出了 NDCG 等指标；使用现成评测库时核对增益映射、截断位置和无相关结果约定，不能只比较指标名称。

## 4. 把回答拆成能核对的陈述

第二课已经让回答由多条陈述组成。人工核对时，将其中可单独判断真假的事实分开，查看实际送入的证据是否支持它们。

本课采用以下报告口径，它们是课程的操作定义。

| 指标             | 分子与分母                                                |
| ---------------- | --------------------------------------------------------- |
| 事实支持率       | 被实际证据完整支持的事实陈述数 / 全部事实陈述数           |
| 引用支持率       | 引用片段确实支持其所附陈述的配对数 / 全部陈述与引用配对数 |
| 有依据引用覆盖率 | 至少有一组引用能完整支持的事实陈述数 / 全部事实陈述数     |
| 要点完成率       | 正确回答的必要要点数 / 人工标注的必要要点数               |

一句话需要两块共同支持时，按这组证据判断是否完整；每个引用配对另检查它是否确实支持句子中的相应内容。引用一个不相关片段不能用另一个正确引用抵消。

没有事实陈述的拒答，支持率记为不适用，再检查拒答是否符合预期。没有引用配对时，引用支持率也记为不适用；若存在事实陈述，有依据引用覆盖率就是零。报告必须列出适用题数，不能让没有内容的回答靠空分母拿到高分。

用初始 D1 作为证据，检查下面两句教学候选回答。

1. 只读查询首次失败后最多再试两次。
2. 认证失败也可以再试两次。

两句都附上 D1 的重试段，第一句受支持，第二句与原文矛盾。若每句只附这一处引用，事实支持率、引用支持率和有依据引用覆盖率均为 1/2。来源真实不能消除第二句的错误。

问题是否被回答也要单独看。q3 要问保存期限与更新行为，只回答六十秒可以全部受证据支持，却只完成两个要点中的一个。

## 5. 无答案、拒绝与技术失败

按照题目预期，分别统计依据不足、澄清、不支持和正常回答的行为命中数。每类都写出“符合预期题数 / 该类总题数”。对有答案题额外记录不必要拒答，避免只靠少回答获得较高支持率。

技术失败保存失败阶段与类别，并将本轮比较标为不完整。可以展示已成功题目的指标，但同时给出总题数、成功题数和失败数；不能只删除失败题后宣称整体质量提高。保留初始失败报告，修正后另开一次运行。

权限题除查看答案，还要查看候选、重排输入、生成证据和返回引用中是否出现不允许的片段。注入题先确认攻击文字确实到达指定处理阶段，再判断预期行为。未触发目标机制的用例应标为未覆盖。

## 6. 用量、时间和人工评分一起保存

一次逻辑请求可以包含改写、变体生成、问题编码、检索、重排和回答生成。记录各阶段耗时及总耗时，Token 用量按实际调用分别记录后相加。服务未提供的用量标为未知，离线模型的时间与硬件信息另外保存。

总成本使用实验当日明确记录的计价配置计算，列出币种、单价单位和日期。未知用量对应的成本不能填零。免费试用和本地模型也不能据此推断计算成本不存在。

P50 与 P95 分别描述排序后处于 50% 和 95% 位置的耗时。本课采用最近秩法，N 次有效测量时取从小到大第 `ceil(p × N)` 个值。五个耗时为 100、120、150、180、500 毫秒时，P50 为 150，P95 为 500。小样本主要用于检查口径，不能证明真实高负载下的尾延迟。

评测产物单独保存问题、候选、证据、回答与人工评分，使用公开或合成资料。生产运行日志仍按第一阶段规则避免正文。人工评分可以打乱配置名称，减少先入印象。模型辅助评分必须记录评审模型和规则，并抽样人工复核；不能用它替代全部事实判断。

## 7. 练习与验收

### 任务 1　扩充并冻结评测材料

沿用 20 个问题，扩展到 50～100 条，覆盖第一节的类别。每题给出输入条件、必要事实和可定位证据，无答案题解释在当前可见资料中缺少什么。

通过条件是两种配置使用同一材料版本，权限和更新题的身份、快照明确，注入与冲突材料完整保存在评测集合中。书面说明开发集与比较集的用途。此任务包含人工标注，不要求新增生成模块。

### 任务 2　运行完整评测并比较两个配置

**目标。** 让每题经过真实应用处理流程，自动保存运行记录，导入人工评分后生成差异报告。

扩展已有评测入口，先运行问题并导出结果，再导入人工评分。缺少人工评分时标记未评分，不填默认满分。增加按问题编号对照两次运行的报告，比较前先核对语料、标注版本与输入条件。

通过条件如下。

- 组件测试复现本课 NDCG、支持率和最近秩例子，覆盖零分母、空返回和非法等级。
- 流程测试从批量入口驱动与 HTTP 共用的回答流程，保存实际候选、入选证据、模型输入对应关系和终止状态。
- 多轮题由会话入口依次提交，各轮历史由应用保存。拒答、权限和注入用例实际到达被检查的边界。
- 真实模型完成固定材料的两组配置实验，人工检查回答与引用，报告逐题变化、适用题数、失败数、用量与时间。
- 两份运行的材料版本不兼容时拒绝直接给出优劣结论；遗漏或多出的题号单独报告。

报告至少解释三个结果，分别涉及证据遗漏、回答或引用错误，以及质量与成本的取舍。没有出现某类错误时，使用本课明确的教学反例检查判分，不能编造真实实验失败。

### 知识检查

事实支持率为 1 是否代表回答完整？为什么查到证据却没有送入模型需要单独记录？两种切块策略的相关片段数不同，怎样比较证据覆盖？

通过条件是明确每个分母与输入条件，不用一个总分代替检索、生成和运行失败的分析。
