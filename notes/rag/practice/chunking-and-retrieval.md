# 文档切块与片段检索

第二阶段按整篇短文档计算相关性。一份手册变长后，“怎样重试”的答案可能只占其中一段。把整本手册交给模型会占用更多输入空间，检索结果也不便指出具体依据。

本课把一份文档拆成多个可单独检索的文本块。完成后，用户输入问题，程序返回片段、分数和来源，能够按位置找到同一段原文。本课仍只展示检索结果。

## 学习前提与本课范围

复用[文档读取](../foundations/retrieval-and-documents.md)和[向量检索](../foundations/embeddings-and-search.md)。这里首次引入文本块，英文 Chunk，指从一篇文档中截取、作为一次检索候选的连续文本。

本课先按字符长度切分，方便直接检查位置。Python 字符串切片以 Unicode 码点计数，这个单位与 Token 不同。实际送入 Embedding 模型前，仍要检查包含标题、前缀等内容的完整编码输入。模型超过长度限制时明确失败，不能静默截断。

## 1. 文档身份与片段身份

原来的文档记录继续保存完整正文。片段记录引用它，并增加自己的位置与编号。

| 信息             | 含义                     | 由谁使用             |
| ---------------- | ------------------------ | -------------------- |
| 文档编号与版本   | 指向此次切分所依据的正文 | 原文回查与版本核对   |
| 片段编号         | 唯一标识一条切块结果     | 向量对应、排序和引用 |
| 起点与终点       | 在规范化正文中的字符区间 | 从正文还原片段       |
| 片段正文         | 该区间中的连续文字       | 编码和展示           |
| 标题、来源与章节 | 帮助读者识别依据         | 结果展示与后续引用   |

规范化正文沿用第二阶段的读取结果，换行处理和首尾清理在切块之前完成。区间起点包含在内，终点不包含在内，与 Python 的切片约定一致。片段正文应等于该版本正文的对应切片；切块后再次清除首尾空白会改变这一对应关系。

第一课固定资料版本和切块配置。片段编号可由文档编号、资料版本、切块配置标识和区间生成。相同输入重复准备时，编号保持一致，增加其他文档不改变已有编号。第三课再处理正文和切法发生变化的情况。

章节表示片段所在的标题范围。本课可以先保存文档标题作为章节位置；没有细分章节时明确记为未细分。第三课引入按标题切分后再增加完整标题层级，不要求提前实现 Markdown 解析器。

## 2. 用十四个字母看清切块

设正文为下面的教学字符串。

```text
ABCDEFGHIJKLMN
```

块长 L 为 6，重叠 O 为 2。重叠指相邻两块重复包含的字符数，用来让靠近边界的短语有机会完整出现在另一块中。每次向前移动 `L - O` 个字符。

| 块  | 区间      | 正文     | 与前一块重复的内容 |
| --- | --------- | -------- | ------------------ |
| 1   | `[0, 6)`  | `ABCDEF` | 无                 |
| 2   | `[4, 10)` | `EFGHIJ` | `EF`               |
| 3   | `[8, 14)` | `IJKLMN` | `IJ`               |

第三块已经到达正文末尾，处理到这里结束。继续从位置 12 输出 `MN` 会重复生成一个已被完整覆盖的尾块。

这三块共编码 18 个字符，原文只有 14 个。重叠增加了重复内容，也增加了编码和后续上下文占用。它不能保证每条事实都完整地落在某一块里。

本课采用以下边界约定。

- L 和 O 都是整数，L 大于零，且 `0 <= O < L`。无效参数在切分前拒绝。
- 空正文产生零块。长度小于或等于 L 时只产生一块。
- 最后一块保留实际长度，到达原文末尾就停止。
- 所有非空正文字符至少被一个片段覆盖，片段不得跨越文档边界。

先遮住上表，把 O 改成 0，自己写出结果。应得到 `ABCDEF`、`GHIJKL`、`MN`。这里最后的 `MN` 尚未被前一块覆盖，因此需要保留。

## 3. 切块后，检索流程有哪些变化

切块把检索的单位从整篇文档改为片段。

```text
文档准备入口
读取完整文档 → 切成带身份和位置的片段 → 编码片段 → 保存片段与向量的对应关系

单次查询入口
问题编码 → 与片段向量比较 → 按分数排序 → 取前 K 块 → 返回片段与原文位置
```

问题的编码方法继续与文档侧配套。文档侧改为逐片段编码，可以把标题与片段正文按固定规则拼接，但要记录这一规则。回查显示的原文仍取保存的片段，不拿拼接后的编码文本冒充原文。

每次查询最多返回 K 个片段。分数并列时按片段编号升序排列。同一篇文档的多个片段都排进前 K 时，查询会分别返回这些片段。不同文档中的相同文字也保留各自来源。后续如需合并证据，应说明合并规则。

关键词基线可以复用原有分词与计分规则，计分单位同样改成片段。向量检索与关键词检索必须使用相同的切块集合，才能比较谁找到了哪条证据。

## 4. 用原文判断切块是否有用

打开[实战教学材料](practice-materials.md)，在“初始资料”下找到“文档 D1”。用“认证失败还要重试吗”作为查询。设某次切分把“认证失败”留在前一块，把“立即停止”留在后一块。两块都有部分相关文字，但单独拿出一块可能读不完整。

先检查位置是否正确，再检查块长和重叠。不要因为片段没有完整答案就改动相似度公式。第三课会用按段落与标题切分的方法比较这种边界损失。

原来的评测标注是文档级别。相关文档中某一块可能没有回答依据，不能把该文档的所有片段都自动标为相关。本课保留原有文档评测作为回归检查，另挑三个问题人工标出需要的片段或原文范围。第三课会用不随切法变化的证据范围比较策略。

## 5. 练习与验收

### 任务 1　生成可回查的文本块

**目标。** 让每个向量候选都有明确身份，能回到实际编码所依据的资料。

在文档准备流程中加入本课的固定长度切分。使用字母例子核对区间，再处理 D1～D3 和已有真实语料。保存块长、重叠、计数单位以及编码拼接规则。

通过条件如下。

- 字母例子返回表中的三块，空正文、短正文、末尾不足整块与无效参数符合本课规则。
- 逐块回查对应版本的正文，切片与片段文字完全一致。重复准备的编号稳定，跨文档不会串接。
- 标题、来源、章节位置和片段编号可供查询使用。没有细分章节的情形有明确值。
- 测试覆盖重叠为零、重叠接近块长和恰好覆盖末尾，确认不会多生成已完整覆盖的尾块。

### 任务 2　从查询入口返回片段

**目标。** 将新的检索单位接到用户实际使用的入口。

复用任务 1 的准备结果，让关键词与向量两种方法返回片段、分数和原文位置。用预设编码结果测试排序，用真实 Embedding 单独试查至少三个问题。

通过条件如下。

- 流程测试从查询入口开始，由应用完成问题编码、排序和片段回查，测试不手动拼接这些步骤。
- 同一文档的两个片段能分别进入结果，排序并列、无结果、无效 K 和空查询延续已有约定。
- 超长编码输入实际到达长度检查后被拒绝，未发起编码调用；向量维度等检查继续有效。
- 真实试查保留问题、片段编号、分数与原文，说明至少一处切块边界对阅读的影响。离线测试与真实模型观察分别记录。

格式化、lint 和回归测试作为这两项任务的收尾。数据库、生成回答和资料更新均留给后续课程。

### 知识检查

解释片段编号为什么不能只使用遍历次序。说明字符长度小于 L 为什么仍可能超过模型输入限制。再用字母例子说明重叠带来的收益与重复成本。

通过条件是能明确指出身份、编码输入与原文位置三个不同用途，并正确算出例子中的 18 个编码字符。
