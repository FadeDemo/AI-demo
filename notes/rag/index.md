# RAG 学习

RAG 先从资料中检索证据，再让模型结合证据回答问题。本目录按学习阶段分成两个专题，分别对应 Roadmap 的第二阶段和第三阶段。

| 专题                             | 学习内容                                                       | 完成后的产物                               |
| -------------------------------- | -------------------------------------------------------------- | ------------------------------------------ |
| [检索基础](foundations/index.md) | 文档读取、向量与关键词检索、检索评测，以及融合与重排的基本概念 | 能比较两种检索方法的程序与固定问题评测报告 |
| [RAG 实战](practice/index.md)    | 文档切块、带引用回答、资料更新、混合检索、完整评测与部署       | 一个带引用、可评测、能在本机部署的知识库   |

先完成检索基础，再进入 RAG 实战。两个专题都包含概念讲解、练习和验收，具体任务及前置能力见各自目录。

第二阶段的[练习回答](foundations/answers/index.md)与配套图片保存在检索基础专题内。实际代码、测试和实验数据继续放在 [RAG Knowledge Base 项目](../../projects/rag-knowledge-base/README.md)中，后续课程沿用已有实现逐步扩展。

整体学习顺序见 [Roadmap](../roadmap.md)。
