# 向量与相似度

如果程序把问题和文档各表示成一组数字，就能用数字计算它们有多接近。本课先把这一步算明白。文本怎样变成数字，留给下一课。

做完本课，你会有一个能检查输入并计算相似度的组件。它会被下一课的向量检索直接使用，不需要另建应用入口。

## 1. 向量先看成有顺序的数字列表

`[3, 4]` 是一个二维向量，表示它有两个按顺序排列的数。`[3, 4, 0]` 有三个数，属于三维向量。维度就是每个向量包含的数的个数。

在二维图上，可以从原点画一根指向坐标 `(3, 4)` 的箭头。箭头有方向，也有长度。向量 `[6, 8]` 与它方向相同，长度变成两倍。

这幅图只帮助理解计算。真实文本向量往往有几百个数，每个位置的作用由模型训练形成，不宜自行把第一个数叫作“技术程度”、第二个数叫作“情感程度”。第三课再说明文本与模型的关系。

比较时，两边必须有相同的维度。更进一步，两组数字还必须来自兼容的表示方法。任意两个三维列表虽然能做运算，算出的结果未必能解释为文本相关性。

## 2. 点积与长度怎样算

点积把对应位置相乘，再把乘积加起来。向量的长度也称为范数，本课使用欧氏长度。

```text
a = [3, 4]
b = [1, 0]

a · b = 3 × 1 + 4 × 0 = 3
||a|| = sqrt(3² + 4²) = 5
||b|| = 1
```

`sqrt` 表示平方根，符号 `||a||` 表示向量 a 的欧氏长度，用来描述向量的大小。例如，`[3, 4]` 的维度是 2，欧氏长度是 5。向量长度与原始文档的字数没有直接换算关系。

从原点画出两个向量的箭头，它们之间的角度称为夹角。点积同时受两个向量的长度和夹角影响。保持 b 为 `[1, 0]`，以上面的 a 为起点，分别观察两种变化。

| 情况                      | a        | a 的长度 | 与 b 的点积 |
| ------------------------- | -------- | -------- | ----------- |
| 初始情况                  | `[3, 4]` | 5        | 3           |
| 长度变为两倍，夹角不变    | `[6, 8]` | 10       | 6           |
| 长度不变，与 b 的夹角变小 | `[4, 3]` | 5        | 4           |

## 3. 余弦相似度主要比较方向

如果希望排除长度的影响，只比较两个非零向量的方向关系，可以用余弦相似度。它用点积除以双方的长度。

```text
cosine(a, b) = (a · b) / (||a|| × ||b||)
cosine([3, 4], [1, 0]) = 3 / (5 × 1) = 0.6
cosine([6, 8], [1, 0]) = 6 / (10 × 1) = 0.6
```

对非零实数向量，余弦值在 -1 到 1 之间。方向相同为 1，垂直为 0，方向相反为 -1。采用这种相似度检索时，分数越大，排名越靠前。

余弦相似度描述两个向量的方向关系。将它用于文本检索时，分数能否反映文本的相关性，还取决于生成向量的模型和具体任务。

### 点积与余弦可能排出不同顺序

固定问题向量 q 为 `[1, 0]`，比较下面两篇文档的教学向量。

| 文档向量          | 与 q 的点积 | 与 q 的余弦相似度 |
| ----------------- | ----------- | ----------------- |
| A 为 `[0.8, 0.6]` | 0.8         | 0.8               |
| B 为 `[2, 2]`     | 2           | 约 0.7071         |

按点积，B 排在前面；按余弦，A 排在前面。同一组向量采用不同的计算方法，可能得到不同的排序。下一课使用模型生成文本向量时，再说明如何选择与模型配套的计算方法。

## 4. 归一化与欧氏距离

本课的归一化指把每个分量除以向量的欧氏长度。处理后，非零向量的长度变为 1，方向保留。

```text
[3, 4] / 5 = [0.6, 0.8]
```

两个向量都归一化为长度 1 后，点积与余弦相似度相等。只归一化其中一个向量时，不能保证两者相等。

欧氏距离比较两个点相隔多远，做法是各位置相减、平方、求和，再开平方。

```text
distance(a, b) = sqrt(sum((a_i - b_i)²))
```

欧氏距离越小，两个向量越接近，因此按距离从小到大排序。前面的余弦相似度则按分数从大到小排序。

当两个向量都已经归一化时，有下面的关系。

```text
distance(a, b)² = 2 - 2 × cosine(a, b)
```

所以在两侧都归一化的前提下，余弦从大到小和欧氏距离从小到大会产生相同的排序。没有这个前提时，不能直接套用。

前面的等式左侧是欧氏距离的平方。使用检索库时，需要分清返回值表示距离还是距离的平方。例如，向量检索库 [Faiss 的 L2 检索](https://github.com/facebookresearch/faiss/wiki/MetricType-and-distances)返回平方欧氏距离，对应 `distance(a, b)²`；本课的 `distance(a, b)` 返回欧氏距离，代入这个等式前需要先平方。

## 5. 先处理无法计算的输入

全零向量没有方向，余弦计算的分母为零。把这种结果填成 0，会把“无法计算”与“两个非零向量垂直”混在一起。本课规定零向量应明确报错，不能参与余弦排名。

同样拒绝空向量、维度不同，以及含有非数字、无穷大或 NaN 的输入。NaN 表示无法作为有效数值继续运算的结果，在排序中保留它可能造成难以察觉的问题。

浮点数会有很小的舍入误差。自动化测试比较计算结果时，用容差判断，例如误差小于 `1e-6`。展示时可以保留四位小数，但排序使用未四舍五入的分数。

用 NumPy 写局部计算时，`np.dot` 可以求点积，`np.linalg.norm` 可以求向量长度。本课先一次比较两条向量。接口细节见 [NumPy 范数文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.norm.html)。

## 7. 练习与验收

### 任务 1　实现带输入检查的余弦计算

**目标。** 给下一课提供可依赖的比较方法，并让非法向量在排序之前失败。

在同一个配套项目中实现余弦计算。它接收两条向量，先检查输入，再返回相似度。使用 NumPy 或等价的明确计算都可以，不限定函数名。

通过条件如下。

- `[1, 0]` 与自身、`[0, 1]`、`[-1, 0]` 的结果依次为 1、0、-1。
- `[3, 4]` 与 `[1, 0]` 的结果为 0.6；把前者放大为 `[6, 8]`，结果保持一致。
- 空向量、维度不一致、零向量和非有限数值均被明确拒绝。测试比较数值时使用声明的容差。
- 将前文 A、B 的余弦结果与手算值核对。原始计算结果保留精度，展示保留几位小数由项目说明。

本任务的产物是一个计算组件，直接调用它就能验收。下一课才要求通过应用入口完成文本编码和排名，不在本课提前接入模型。
