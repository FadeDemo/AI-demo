# 词法检索与排名融合练习回答

本文保存[词法检索与排名融合](../lexical-and-hybrid-search.md)课程的任务 1、任务 2 与知识检查回答。任务 1 的统计与计算按学习者作答整理，其余内容为参考回答。

## 任务 1　解释词项统计与评分

### TF 与 DF

使用课程中的三篇教学文档。

| 文档 | 正文                  |
| ---- | --------------------- |
| A    | `timeout retry retry` |
| B    | `timeout log`         |
| C    | `log log`             |

TF 统计一个词项在某篇文档中出现的次数。DF 统计整批语料中包含该词项的文档数，每篇包含它的文档计一次。

| 词项      | TF(A) | TF(B) | TF(C) | DF  |
| --------- | ----- | ----- | ----- | --- |
| `timeout` | 1     | 1     | 0     | 2   |
| `retry`   | 2     | 0     | 0     | 1   |
| `log`     | 0     | 1     | 2     | 2   |

`retry` 在 A 中出现两次，所以它在 A 中的 TF 为 2。包含它的文档只有 A，DF 为 1。

### A 中的 TF-IDF

沿用课程的手算公式，其中 `t` 是词项，`d` 是当前计算权重的文档。公式采用自然对数 `ln`，语料总数为 `N = 3`。

```text
idf(t) = ln(N / df(t))
tf_idf(t, d) = tf(t, d) × idf(t)
```

`timeout` 的 DF 为 2，在 A 中的 TF 为 1。

```text
idf(timeout) = ln(3 / 2) ≈ 0.4055
tf_idf(timeout, A) = 1 × ln(3 / 2) ≈ 0.4055
```

`retry` 的 DF 为 1，在 A 中的 TF 为 2。

```text
idf(retry) = ln(3 / 1) = ln(3) ≈ 1.0986
tf_idf(retry, A) = 2 × ln(3) ≈ 2.1972
```

### 第一课为何只统计不同词项

第一课先建立一个容易核对的关键词检索基线。查询和文档分词后都转换为不重复的词项集合，分数等于两个集合交集中词项的数量。重复词项合并后只保留一项，每个匹配词项都计 1 分。

这套简化规则便于先验证从输入查询到返回排名的完整流程，也为后续评分方法提供一个可复查的比较起点。[第一课的计分约定](../retrieval-and-documents.md#只数命中了几个不同词项)

### BM25 怎样处理重复和篇幅

直接按词频累加权重时，同一个词每多出现一次，增加的权重相同，大量重复容易累积高分。BM25 的词频饱和让重复出现仍能增加得分，同时使每次增加的分数逐渐减小，限制大量重复对评分的作用。

长文档通常有更多机会包含查询词，词频也可能随篇幅增长。BM25 将文档长度与语料的平均长度一起考虑，调整词频对得分的贡献，减少文档篇幅差异带来的影响。

### 倒排索引与评分方法各自负责什么

倒排索引保存词项出现在哪些文档中，还可以记录各篇文档中的词频。查询包含 `retry` 时，可以通过索引直接找到 A。

评分方法定义如何利用词项统计计算候选文档的分数，检索程序再根据分数排列文档。第一课的不同词项命中数、TF-IDF 和 BM25 都属于评分规则的选择。

## 任务 2　核对一次排名融合

### 排名与计算规则

采用课程给出的两份完整排名，每一路的位置都从 1 开始。

```text
词法排名 = [A, B, C, D, E]
向量排名 = [D, B, C, A, F]
```

按倒数排名融合（RRF）的规则，文档在某一路中排第 r 位，该路贡献为 `1 / (c + r)`。文档缺席某一路时，该路贡献为 0。将两路贡献相加，再按总分降序排列，分数并列时按文档编号升序排列。

下面的小数保留八位，排序依据精确分数。

### c 为 1 时

| 文档 | 词法贡献 | 向量贡献 | RRF 合计   |
| ---- | -------- | -------- | ---------- |
| A    | `1/2`    | `1/5`    | 0.70000000 |
| B    | `1/3`    | `1/3`    | 0.66666667 |
| C    | `1/4`    | `1/4`    | 0.50000000 |
| D    | `1/5`    | `1/2`    | 0.70000000 |
| E    | `1/6`    | 0        | 0.16666667 |
| F    | 0        | `1/6`    | 0.16666667 |

A 的两路贡献相加为 `1/2 + 1/5 = 0.7`。B 的两路贡献相加为 `1/3 + 1/3 = 2/3`，约 0.66666667。

A、D 同分，按编号将 A 排在 D 前。E、F 也同分，E 排在 F 前。最终顺序为 `[A, D, B, C, E, F]`。

### c 为 60 时

| 文档 | 词法贡献 | 向量贡献 | RRF 合计   |
| ---- | -------- | -------- | ---------- |
| A    | `1/61`   | `1/64`   | 0.03201844 |
| B    | `1/62`   | `1/62`   | 0.03225806 |
| C    | `1/63`   | `1/63`   | 0.03174603 |
| D    | `1/64`   | `1/61`   | 0.03201844 |
| E    | `1/65`   | 0        | 0.01538462 |
| F    | 0        | `1/65`   | 0.01538462 |

A 的两路贡献相加为 `1/61 + 1/64 = 125/3904`，约 0.03201844。B 的两路贡献相加为 `1/62 + 1/62 = 1/31`，约 0.03225806。

仍按编号处理 A、D 以及 E、F 的并列，最终顺序为 `[B, A, D, C, E, F]`。

c 从 1 增大到 60 后，同一路中各名次的贡献差距缩小。B 在两路中都排第二，这时它的总分超过了一路第一、另一路第四的 A 和 D。

### E、F 缺席一路时怎样处理

E 只出现在词法排名的第五位，贡献为 `1 / (c + 5)`，向量贡献为 0。F 只出现在向量排名的第五位，词法贡献为 0，向量贡献为 `1 / (c + 5)`。因此两者在 c 为 1 时都得 `1/6`，在 c 为 60 时都得 `1/65`。

### 从第四课选一个值得比较的查询

选用第四课固定评测中的 q09。

> 聊天已经显示了一半，后面的读取突然报错，这半截内容和后续重发该怎样处理？

固定标注中有两篇相关文档。流中断文档说明保留已展示内容、提示回答不完整，以及停止自动重试和释放资源。重试分类文档说明是否再次发送要考虑已展示内容、剩余时间和尝试次数。[流中断原文](../../../../projects/rag-knowledge-base/data/docs/output/stream-failure.md)、[重试分类原文](../../../../projects/rag-knowledge-base/data/docs/requests/retryable-errors.md)

| 相关文档                       | 关键词排名 | 向量排名 |
| ------------------------------ | ---------- | -------- |
| `output/stream-failure.md`     | 1          | 1        |
| `requests/retryable-errors.md` | 前五名之外 | 2        |

K 为 5 时，关键词方法找回一篇相关文档，Recall@5 为 0.5。向量方法找回两篇，Recall@5 为 1，两种方法的 RR@5 都为 1。问题与重试分类文档只共享“内容”一个词项，问题中的“重发”与文档中的“再次发送”没有产生共同词项。[第四课 q09 的排名分析](retrieval-evaluation.md)

这题值得比较混合方法，因为向量一路补回了词项重合较少的相关资料。两路前五名的候选合并后包含两篇相关文档，可以进一步观察它们经过融合后各排在哪里。比较时沿用相同的标注和 K，分别计算融合结果的 Recall@5 与 RR@5，再与已有两种结果对照，判断融合后的前五名能否保留完整依据，以及第一篇相关资料的位置是否变化。

## 知识检查

### 同一个词在一篇文档里出现十次，DF 为何只增加一篇

TF 统计词项在某篇文档中的出现次数，DF 统计整批语料中包含该词项的文档数。计算 DF 时，每篇文档只要包含这个词项，就计一次。

假设 `retry` 在一篇文档中出现十次，它在这篇文档中的 TF 为 10，这篇文档给 `retry` 的 DF 贡献 1。计算整个语料的 DF 时，再数出其余包含 `retry` 的文档，每篇各贡献 1。

### 原始分数直接相加前需要处理什么

先处理两路分数的尺度差异，并明确组合规则。词项命中数、BM25 得分和余弦相似度各有自己的计算含义，数值范围和分布也可能不同。直接将 BM25 得分 12 与余弦相似度 0.8 相加，得分较大的那一路容易主导结果。

采用分数相加时，应明确如何校准或归一化各路分数，以及两路各占多大权重，再用固定问题和人工标注检查组合后的排名效果。

### RRF 为什么不能保证相关性

RRF 根据文档在各路排名中的位置计算贡献。某篇文档是否能回答问题，仍要结合问题与原文判断。

假设一篇无关文档在两路中都排第一，按本课的等权规则，它的 RRF 得分就是 `2 / (c + 1)`，会排在融合结果的首位。

因此，融合效果需要用人工标注核对，并通过 Recall@K、RR@K 等指标检查相关资料是否被找回、排在什么位置。
