# 向量与相似度知识检查

本文保存本课知识检查的参考回答。题目见[向量与相似度课程](../vectors-and-similarity.md#知识检查)。

## 向量维度、向量长度和文本长度分别指什么

以向量 `[3, 4, 0]` 为例，三者关注的内容不同。

| 概念     | 含义                                                 | 这个例子中的结果                   |
| -------- | ---------------------------------------------------- | ---------------------------------- |
| 向量维度 | 向量包含多少个按顺序排列的分量                       | 3，末尾的 0 也占一个分量           |
| 向量长度 | 根据各分量计算出的欧氏长度，用来描述向量的大小       | 5                                  |
| 文本长度 | 原始文本包含多少内容，需要明确字数、字符数等统计单位 | 需要查看原始文本，无法仅凭向量确定 |

向量的欧氏长度由各分量的平方和开平方得到。

```text
||[3, 4, 0]|| = sqrt(3² + 4² + 0²) = sqrt(25) = 5
```

原始文本的字数需要另行统计。向量维度、向量长度与文本字数之间没有直接换算关系。

## 为什么点积和余弦可能产生不同排名

点积同时受向量长度和夹角影响。余弦相似度把点积除以双方的欧氏长度，比较两条非零向量的方向关系。

固定问题向量 q 为 `[1, 0]`，使用课程中的两条文档向量比较。

| 文档向量          | 欧氏长度  | 与 q 的点积 | 与 q 的余弦相似度        |
| ----------------- | --------- | ----------- | ------------------------ |
| A 为 `[0.8, 0.6]` | 1         | 0.8         | 0.8                      |
| B 为 `[2, 2]`     | `sqrt(8)` | 2           | `1 / sqrt(2)`，约 0.7071 |

按点积从大到小排，B 在 A 前面。B 的长度更大，长度对得分的影响使它的点积超过 A。余弦消除长度影响后，A 与 q 的方向更接近，分数更高，因此 A 排在 B 前面。

## 为什么双方归一化后可以用点积代替余弦

对两条同维度的非零向量 a 和 b，分别除以各自的欧氏长度，将处理后的向量记为 u 和 v。

```text
u = a / ||a||
v = b / ||b||
||u|| = ||v|| = 1
```

点积中每一项都除以相同的双方长度乘积，因此可以把这个分母提到求和之外。

```text
u · v = (a · b) / (||a|| × ||b||)
      = cosine(a, b)
```

归一化保留方向，所以两条向量的余弦相似度保持不变。归一化后的点积既等于原向量的余弦相似度，也等于归一化后两条向量的余弦相似度。
