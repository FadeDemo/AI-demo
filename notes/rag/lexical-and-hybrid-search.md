# 词法检索与排名融合

第一课只数命中了多少个不同词项。这个办法容易核对，也留下了几个具体问题。一个词在文档里出现多次要不要加分？所有文档都在用的词，与只出现过一次的标识符，要不要同样计分？

本课先说明更细的词法评分，再用两份固定排名演示怎样合并结果。任务以手算与书面分析为主，BM25 与混合检索的程序实现留到后续 RAG 实战。

## 1. 按词项匹配也可以有不同评分方法

按文字词项匹配来检索，称为词法检索，英文为 Lexical Retrieval。第一课的计数、TF-IDF 和 BM25 都可以在这类方法中讨论。它们采用的计分规则不同，不宜把第一课的简单基线当成全部词法检索方法的效果。

先固定三篇教学文档，内容只用于计数。

| 文档 | 正文                  |
| ---- | --------------------- |
| A    | `timeout retry retry` |
| B    | `timeout log`         |
| C    | `log log`             |

词频 TF 指一个词项在一篇文档中出现多少次。A 中 `retry` 的 TF 为 2。文档频率 DF 指有多少篇文档包含这个词项；这里 `retry` 的 DF 为 1，`timeout` 的 DF 为 2。

两者不能混算。C 中 `log` 出现两次，仍只给 `log` 的文档频率贡献一篇。

## 2. 倒排索引先帮助找到包含词项的文档

第一课可以逐篇扫描词项集合。文档多了以后，可以预先保存“某个词项出现在哪些文档里”的表，这张表称为倒排索引。

| 词项      | 文档及其中的词频 |
| --------- | ---------------- |
| `timeout` | A 为 1，B 为 1   |
| `retry`   | A 为 2           |
| `log`     | B 为 1，C 为 2   |

查询含有 `retry` 时，程序可以直接找到 A，再按声明的规则计分。索引保存哪些文档含词项，评分规则决定这些文档怎么排列。采用倒排索引并不自动等于采用 BM25，也不会自动理解没有共同词项的同义表达。

中文切分仍会影响结果。第一课的“请求超时”拆出了“求超”，换成中文分词工具后词项会变化。若要比较切分方法，应保留固定问题与标注，单独记录这项变化，不能同时换评分方法再把收益全部归给其中一项。

## 3. TF-IDF 给常见程度不同的词不同权重

IDF 指逆文档频率。直觉是某个词出现在越多文档里，越难靠它区分该选哪篇。一个简单版本写作下面这样。

```text
N = 语料中的文档数
df(t) = 包含词项 t 的文档数
idf(t) = ln(N / df(t))
tf_idf(t, d) = tf(t, d) × idf(t)
```

这里 `ln` 表示自然对数。使用三个教学文档，`retry` 的 IDF 为 `ln(3)`，约 1.0986；`timeout` 的 IDF 为 `ln(3/2)`，约 0.4055。在 A 中，`retry` 的这个版本的 TF-IDF 为 `2 × ln(3)`，约 2.1972。

这只是用于手算的一种定义。实际库可能对 TF 取对数、给 IDF 加平滑项，再进行文档长度归一化。对照结果时，要核对库使用的公式，不能只看到名字一样就要求数值相同。[信息检索教材](https://nlp.stanford.edu/IR-book/html/htmledition/inverse-document-frequency-1.html)讨论了文档频率与词项区分作用。

如果把语料中每个词项都分配一个位置，一篇文档只在自己包含的词项位置填写权重，其他位置填零，就得到按词项组织的向量。大部分位置为零时，称为稀疏向量，英文为 Sparse Vector。本课只讨论这种按词项计数和加权得到的表示。

## 4. BM25 怎样看重复和篇幅

BM25 也是一种常用的词法评分方法。它使用词项的常见程度，同时调整词频和文档长度的影响。

一个词在文档中出现更多次，通常会增加相应得分，但增量会逐渐减小。这种变化叫词频饱和。文档很长时，零散提到一个词的意义也可能与短文中集中讨论它不同，BM25 会结合文档长度和语料的平均长度调整评分。

例如，Apache Lucene 的 BM25 实现用 `k1` 调整词频饱和，用 `b` 调整文档长度对词频的影响。这是该实现公开的参数用法，具体配置入口应查看实际使用的库。[Lucene 10.0 的相似度文档](https://lucene.apache.org/core/10_0_0/core/org/apache/lucene/search/similarities/package-summary.html)说明了两项参数。本课只要求能解释它们针对什么问题，不要求调参或背公式。

词法方法能够保留明确出现的编号、产品名或配置项。若问题与文档用词差别很大，单靠这些词项仍可能漏检。向量表示可以提供另一种相关性线索，实际是否有帮助要看第四课的结果。

## 5. 混合检索怎样合并两种线索

混合检索，英文为 Hybrid Search，在本课指对同一个问题同时运行词法方法与稠密向量方法，再合并候选文档与排名。两路都只处理它们各自的输入和分数，应用通过文档编号确认两路结果各指向哪篇资料。

原始分数经常不在同一尺度上。词项命中数 3、BM25 得分 12 和余弦相似度 0.8，各有自己的计算含义。没有明确的校准或融合规则时，直接相加可能使某一路仅因数值较大就支配排名。

一种可用的办法是只利用排名。RRF 是 Reciprocal Rank Fusion 的缩写，常译为倒数排名融合。每一路中的位置从 1 开始，某文档每出现一次，就得到 `1 / (c + 位置)` 的贡献，最后相加。

```text
某篇文档的 RRF 分数
= 词法排名中的贡献 + 向量排名中的贡献

某一路贡献 = 1 / (c + 该路中的位置)
该路没有这篇文档时，贡献为 0
```

c 是正的平滑常数。较小时，前后位置的贡献差别较大；变大后，相邻位置的差距减小。c 与返回数量 K 分开。本课采用两路等权，最终并列时按文档编号升序排列。

[Elasticsearch 的 RRF 说明](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion)提供了按排名融合的用法。本课只用它解释通用方法，不要求采用 Elasticsearch，也不把某个产品的默认参数当成统一规定。

### 一组可以完整手算的排名

```text
词法排名 = [A, B, C, D, E]
向量排名 = [D, B, C, A, F]
c = 1
```

| 文档 | 词法贡献 | 向量贡献 | 合计      |
| ---- | -------- | -------- | --------- |
| A    | 1/2      | 1/5      | 0.7       |
| B    | 1/3      | 1/3      | 约 0.6667 |
| C    | 1/4      | 1/4      | 0.5       |
| D    | 1/5      | 1/2      | 0.7       |
| E    | 1/6      | 0        | 约 0.1667 |
| F    | 0        | 1/6      | 约 0.1667 |

所以融合顺序为 `[A, D, B, C, E, F]`。文档 E 没有出现在向量排名里，这一路就贡献零，不能把它当作排在最后一位后再加一项分数。

两路同时把某篇错误文档排在前面，RRF 也可能继续把它排得很高。融合完成后仍要用人工标注评测，不能把两种方法叠在一起当作效果必然提高的证据。

## 6. 交互观察

打开[排名融合实验](../../projects/retrieval-usage-lab/index.html#fusion)。

1. 把 c 设为 1，逐行核对上表与最终顺序。
2. 把 c 调到 60，观察 B 与 A、D 的相对次序，并解释每一路贡献怎样变化。
3. 查看 E 和 F，只根据各自实际出现的位置计算一次贡献，确认没有凭空补出另一路的排名。

交互实验使用固定排名，没有执行关键词检索或 Embedding。它演示融合计算，不能说明混合检索在你的语料上一定改善。

## 7. 练习与验收

### 任务 1　解释词项统计与评分

用本课三篇教学文档，写出三个词项各自的 TF、DF，并计算 A 中 `retry` 与 `timeout` 的示例 TF-IDF。说明第一课为何没有使用词频，以及 BM25 的词频饱和与长度调整分别想处理什么问题。

通过条件是 TF 与 DF 没有混淆，数字与本文公式一致，能说明倒排索引和评分方法各自负责什么。此任务是书面计算，不要求实现 TF-IDF 或 BM25。

### 任务 2　核对一次排名融合

使用本课给出的两份完整排名，分别计算 c 为 1、60 时的融合结果。写出 A、B 的两路贡献，说明 E、F 缺席一路时如何处理。随后从自己的第四课报告中找一个值得进一步比较混合方法的查询，说明依据；若暂未看到需要，也据实解释。

通过条件是位置从 1 起算、缺席贡献为零、并列规则明确，建议能对应到实际记录。本阶段不要求新增混合检索入口，不因这个书面练习修改已经完成的关键词与向量基线。

### 知识检查

解释同一个词在一篇文档里出现十次，为何 DF 仍只增加一篇。再说明原始分数直接相加需要先处理什么，以及 RRF 为什么不能保证相关性。
