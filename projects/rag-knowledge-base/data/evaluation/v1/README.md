# 检索评测集 v1

本目录保存[检索评测任务 1](../../../../../notes/rag/retrieval-evaluation.md)的固定材料，沿用 [50 篇练习语料](../../docs/)，共 20 道题，其中 16 道有回答依据，4 道相关文档清单为空。

问题编写和相关性核对由 Codex 完成。每题均以整批 50 篇原文为判断范围。标注记录说明每篇相关文档能为问题提供哪些依据，并保存对应的原文摘录。

## 文件与字段

- [queries.json](queries.json) 的顶层是问题数组，每条记录包含问题编号、原问题、类别、相关文档编号、判断依据和原文摘录。
- [manifest.json](manifest.json) 保存材料版本、标注来源、数量、语料所在的 Git 修订，以及全部语料和问题标注文件的 SHA-256 校验值。

`relevant_doc_ids` 保存相关文档编号。编号沿用文档加载入口的约定，以 `data/docs/` 为起点，使用 `/` 分隔子目录，并保留文件扩展名。编号按升序保存。

`reasons` 按相关文档编号保存判断理由，说明该文档提供了哪一部分回答依据。`evidence` 按相同编号保存原文摘录数组，供读者回到原文核对。多部分问题允许每篇相关文档提供其中一部分依据。

`category` 表示本评测集的问题类别，取值和分布见下一节。当 `category` 为 `unanswerable` 时，`relevant_doc_ids` 为空数组，`reasons` 和 `evidence` 为空对象。这类记录还包含 `unanswerable_reason` 字段，说明语料缺少哪种信息。

## 问题覆盖

本评测集将有答案问题按提问方式分为常见表述、换种说法和精确标识符三类。语料缺少回答依据的问题归入无答案类别。

| 类别               | `category` 值  | 问题编号 | 数量 |
| ------------------ | -------------- | -------- | ---- |
| 常见表述           | `common`       | q01～q06 | 6    |
| 意思相近的换种说法 | `paraphrase`   | q07～q12 | 6    |
| 精确标识符         | `identifier`   | q13～q16 | 4    |
| 资料无答案         | `unanswerable` | q17～q20 | 4    |

无答案判断以这 50 篇语料是否提供所需依据为准。

## 材料版本

材料版本为 `retrieval-evaluation-v1`，创建于 2026-11-12。清单中的语料路径和问题文件路径均相对于清单所在目录解释，SHA-256 根据文件原始字节计算。

任务 2 可以读取问题数组，使用相同版本的语料和相关性标注运行两种检索，再计算指标。文件校验值用于核对本轮比较实际使用的材料。
