# LLM 使用基础交互实验

这个零依赖网页用于配套 [LLM 使用基础课程](../../notes/llm/index.md)，通过教学数据演示上下文预算、temperature 和 top-p。它不会访问网络、调用模型、读取本地文件或保存输入。

## 运行

直接在浏览器打开 `index.html`，或在本目录启动任意静态文件服务器。例如：

```shell
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作与观察

### 上下文预算

1. 把窗口设为 8,000，把各项活跃输入与本轮输出预算的总和调到窗口以内。
2. 增加外部材料直到超出窗口，确认页面显示超出量。
3. 通过减少历史、外部材料或本轮输出预算恢复可发送状态。

### 采样分布

1. 保持 top-p 为 1，分别观察低、中、高 temperature 下的分布。
2. 保持 temperature 不变，降低 top-p，观察候选集合变小。
3. 多次点击“示意采样”，观察选择只来自当前保留集合。

## 教学边界

- Token 数由滑块直接提供，不是 tokenizer 计算结果。
- 滑块只表示各部分的 Token 数量，不能判断具体内容是否适合删除或压缩，也不演示裁剪造成的语义后果。
- 候选分数和采样结果是本地教学数据，不代表任何真实模型。
- 成本、模型窗口和参数范围必须以实际项目所选服务的文档与响应为准。
